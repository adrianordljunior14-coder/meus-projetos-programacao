1. Estrutura básica

Um documento HTML é formado por elementos, geralmente compostos por uma tag de abertura, conteúdo e uma tag de fechamento.

<!DOCTYPE html>
<html lang="pt-BR">
	<head>
		<meta charset="UTF-8">
		<title>Minha página</title>
	</head>
	<body>Conteúdo visível</body>
</html>

<head> guarda metadados; <body> contém o conteúdo exibido.

2. Títulos e texto

Subtítulo de exemplo

Use <h1> a <h6> para títulos e <p> para parágrafos.

Também é possível usar negrito, ênfase, marcação e uma quebra
de linha.

3. Listas

Lista não ordenada (<ul>):

  • Item um
  • Item dois
  • Item três

Lista ordenada (<ol>):

  1. Planejar
  2. Codificar
  3. Testar

5. Formulários

Formulários recebem dados do usuário com campos como <input>, <textarea> e <button>.




Dica: prefira tags semânticas como <header>, <nav>, <main>, <section>, <article> e <footer> para organizar o conteúdo e melhorar a acessibilidade.
