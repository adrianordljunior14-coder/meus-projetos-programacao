🎯 Principais Comandos GIT

Configuração Inicial

Configurar nome de usuário:

git config --global user.name "Seu Nome"

Configurar email:

git config --global user.email "seu@email.com"

Criando e Clonando Repositórios

Inicializar um repositório:

git init

Clonar um repositório:

git clone <url-do-repositório>

Verificando Status e Histórico

Ver status dos arquivos:

git status

Ver histórico de commits:

git log

Ver histórico resumido:

git log --oneline

Adicionando e Comitando Mudanças

Adicionar arquivo específico:

git add <nome-do-arquivo>

Adicionar todos os arquivos modificados:

git add .

Fazer commit:

git commit -m "Mensagem do commit"

Adicionar e fazer commit simultaneamente:

git commit -am "Mensagem do commit"

Trabalhando com Branches

Ver branches locais:

git branch

Criar uma nova branch:

git branch <nome-da-branch>

Mudar de branch:

git checkout <nome-da-branch>

Criar e mudar de branch simultaneamente:

git checkout -b <nome-da-branch>

Deletar uma branch:

git branch -d <nome-da-branch>

Mesclando Branches

Mesclar branch no branch atual:

git merge <nome-da-branch>

Interagindo com Repositório Remoto

Ver repositórios remotos:

git remote -v

Adicionar repositório remoto:

git remote add origin <url-do-repositório>

Enviar commits para repositório remoto:

git push origin <nome-da-branch>

Puxar atualizações do repositório remoto:

git pull origin <nome-da-branch>

Desfazendo Mudanças

Descartar mudanças no arquivo:

git checkout -- <nome-do-arquivo>

Remover arquivo da staging area:

git reset <nome-do-arquivo>

Reverter para commit anterior:

git revert <hash-do-commit>
